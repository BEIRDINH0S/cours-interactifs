comment c'est fait

Le principe

  1. 01
    Zéro dépendance, zéro buildHTML, CSS et JavaScript natifs. Pas de npm install, rien à compiler : on ouvre un fichier et ça marche, aujourd'hui comme dans deux ans.
  2. 02
    Un système de design uniqueassets/css/system.css porte toutes les couleurs et tous les composants. Les deux thèmes, clair et sombre, suivent celui du système.
  3. 03
    Des briques partagéesassets/js/lib/ fournit la figure de graphe, le contrôleur pas-à-pas et le panneau de code. Un nouveau module les réutilise au lieu de les réécrire.
  4. 04
    Les fiches restent dans le vaultCe site sert à comprendre. La mémorisation, elle, a besoin d'un planificateur qui relance : c'est la répétition espacée d'Obsidian, et ça ne bouge pas.

Pour ajouter une matière : un dossier dans modules/ et une entrée dans modules.js. C'est tout.
